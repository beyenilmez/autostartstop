# Security Policy

## Supported Versions

Only the latest release line receives security updates. Older versions are not supported.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

**Do not report security vulnerabilities in public GitHub issues.**

To report a vulnerability:

1. **Use GitHub Security Advisories**  
   Open the [Security](https://github.com/beyenilmez/autostartstop/security) tab and click **Report a vulnerability**. This opens a private advisory so the issue can be discussed and fixed before disclosure.

2. **Include in your report**  
   - A clear description of the vulnerability  
   - Steps to reproduce  
   - Impact (e.g. privilege escalation, information disclosure)  
   - Your environment (Velocity version, Java version, plugin version) if relevant  

3. **What to expect**  
   - Your report will be acknowledged and you can expect a response within a reasonable time.  
   - More details may be requested.  
   - Once the issue is fixed, disclosure can be coordinated and you may be credited if you wish.

Private reports are appreciated so vulnerabilities can be addressed before they are exploited.

## Scope

- **In scope:** AutoStartStop plugin code, configuration handling, and integration with Velocity.  
- **Out of scope:** Vulnerabilities in Velocity itself, in third-party services (e.g. AMP, Pterodactyl), or in the host system. Report those to the respective projects or vendors.
